# 课签 CourseTag

课签是一款为大学生设计的 Android 照片整理工具：批量选择课堂上拍摄的板书、课件照片，在原文件名末尾统一加上课程名称，例如

```
IMG_20260927_143021.jpg  →  IMG_20260927_143021（高等数学）.jpg
```

之后在系统相册或文件管理器中搜索「高等数学」，就能集中找到这门课的所有照片。导入 WakeUp 课程表等应用导出的 ICS 日历后，课签还能根据拍摄时间自动识别每张照片属于哪节课，一键完成整学期的整理。

界面基于 Material 3 Expressive 设计语言，使用系统莫奈取色，完整适配浅色与深色模式，并支持预测性返回手势。

## 功能

- **批量标记课程**：长按照片进入多选，拖动即可连续选择一段照片；按日期整组选择，一次为几十张照片添加课程。
- **课表智能识别**：导入 `.ics` 课程表后，上课时间内拍摄的照片会按「课程 · 第几周 · 星期 · 节次时间 · 教室」归组展示。可以逐节修改识别出的课程、逐张排除照片，确认后一键重命名。
- **快速筛选课上照片**：照片页提供「全部 / 课上拍摄 / 未标记 / 已标记」筛选与相册切换，「课上拍摄」按节次分组，点一下即可选中整节课的照片。
- **重命名预览**：执行前逐张列出原文件名与新文件名，新增、更换或移除的课程部分高亮显示；同名冲突、文件名过长等问题会提前标出并自动跳过，也可以手动取消个别照片。
- **一次确认，批量完成**：所有照片只需在系统弹窗中确认一次；在系统「媒体管理」中授权后可免去确认。
- **随时撤销**：重命名完成后可立即撤销，也可以在「重命名记录」中恢复最近 50 次批量操作。
- **常用课程预设**：提前保存高等数学、大学物理、大学英语等课程，支持一次粘贴多门；标记时可搜索，也可以直接输入新课程。
- **统一修改课程名**：自动识别文件名中已有的课程。修改课程名称时，所有相关照片同步重命名；新名称与已有课程相同时自动合并，两门课的上课时间都会继续用于识别。
- **自定义命名格式**：内置全角括号、半角括号、方括号、方头括号、下划线、短横线、话题标签等格式，也可以自行设定课程名前后的符号。更换格式后，旧格式的照片仍能被识别，并可一键转换为新格式。
- **多学期课表**：可同时导入多个学期的课表，往期照片也能按当时的课表识别；识别的时间范围（课前、课后若干分钟）可调。
- **直接打开课表文件**：在文件管理器或聊天应用中选择「用其他应用打开」即可把 `.ics` 文件交给课签导入。

## 使用方法

1. 首次打开时允许课签访问照片。
2. （可选）在「课程」页导入课程表。以 WakeUp 课程表为例：在 WakeUp 中将课表导出为 ICS 日历文件，再在课签中选择该文件，确认课表名称与需要导入的课程即可。
3. 在「照片」页：
   - 点按「识别到 N 张课上照片未标记」进入确认页，检查每节课的识别结果后预览并重命名；
   - 或长按照片进入多选，点按悬浮工具栏中的标签按钮选择课程。
4. 在预览页确认新文件名，点按「重命名」并在系统弹窗中允许修改。

## 课程表解析

课签按 RFC 5545 解析日历文件，兼容 WakeUp 课程表及常见日历应用的导出格式：

- 折行、`TZID` 时区、UTC 与浮动时间；
- `RRULE` 重复规则（`DAILY`、`WEEKLY`、`MONTHLY`、`YEARLY`，含 `INTERVAL`、`UNTIL`、`COUNT`、`BYDAY`）；
- `EXDATE`、`RDATE`、`RECURRENCE-ID` 单次调课与 `STATUS:CANCELLED`；
- WakeUp 课程表备注中的教室与任课老师；
- 全天事件与提醒（`VALARM`）不会被当作上课时间。

教学周以课表中最早一节课所在周的周一作为第 1 周。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `READ_MEDIA_IMAGES` / `READ_EXTERNAL_STORAGE` | 读取相册中的照片。Android 14 起支持只授权部分照片。 |
| `MANAGE_MEDIA`（可选） | 用户在系统「媒体管理」中授权后，重命名时不再逐次确认。 |

课签不申请网络权限，所有照片与课表数据只在本机处理。重命名只修改文件名，照片内容与拍摄信息保持不变。

## 构建

- Android 11（API 30）及以上，目标 API 36
- JDK 17 或更高版本
- 构建工具：Gradle 9.8、Android Gradle Plugin 9.4、Kotlin 2.4

```bash
./gradlew assembleDebug        # 构建调试版 APK
./gradlew testDebugUnitTest    # 运行单元测试
```

## 技术栈

- Jetpack Compose、Material 3 Expressive（`material3 1.5.0-alpha`）
- Navigation 3（页面导航与预测性返回动画）
- MediaStore `createWriteRequest` 批量获取修改授权
- Kotlin 协程、kotlinx.serialization（本地 JSON 存储）
- Coil 3（缩略图加载）
- Material Symbols Rounded 图标（以矢量资源打包）

## 项目结构

```
app/src/main/java/com/happycola233/coursetag/
├── data/
│   ├── ics/          # ICS 日历解析与重复规则展开
│   ├── media/        # MediaStore 读取与批量重命名
│   ├── naming/       # 命名格式、文件名解析与合法化
│   ├── schedule/     # 上课时段索引、照片与课程匹配、教学周
│   └── AppStore.kt   # 本地数据持久化
├── domain/           # 图库派生视图、重命名方案、课程与课表编辑
└── ui/               # Compose 界面：照片、课程、设置、预览、识别确认等页面
```
