<h1 align="center">课签 CourseTag</h1>

<p align="center">
  给课堂照片的文件名加上课程名，在相册里一搜就能找到整门课的板书和课件。
  <br>
  Android 11+ · Material 3 Expressive · 不联网，照片只在本机处理
</p>

---

课签是为大学生设计的 Android 照片整理工具。批量选择课堂上拍的板书、课件照片，在原文件名末尾加上课程名称：

```
IMG_20260927_143021.jpg  →  IMG_20260927_143021（高等数学）.jpg
```

之后在系统相册或文件管理器中搜索「高等数学」，就能集中找到这门课的所有照片。导入 WakeUp 课程表等应用导出的 `.ics` 日历后，课签会根据拍摄时间判断每张照片属于哪节课，一次整理完整个学期。

## 功能

### 标记照片

- **批量选择**：长按照片进入多选，拖动即可连续选择一段照片，往回拖可以取消；也可以按日期整组选择。
- **快速筛选**：按「全部 / 课上拍摄 / 未标记 / 已标记」筛选，并可切换相册。「课上拍摄」按节次分组，点一下就能选中整节课的照片。
- **大图预览**：从缩略图展开大图，支持双击和双指缩放、左右翻页、拖动关闭；在预览中可以直接标记、更换或移除这张照片的课程，并参考课表给出的建议。
- **常用课程**：提前保存常用课程，支持一次粘贴多门；标记时可以搜索，也可以直接输入新课程。

### 按课表识别

- **导入课表**：支持 WakeUp 课程表等应用导出的 `.ics` 文件，也可以在文件管理器或聊天应用中选择「用其他应用打开」，把文件交给课签。
- **课上照片自动归组**：上课时间内拍摄的照片按「课程 · 第几周 · 星期 · 节次时间 · 教室」归组。可以逐节修改识别出的课程、逐张排除照片，确认后一键重命名。
- **多学期课表**：可以同时导入多个学期的课表，往期照片也能按当时的课表识别；课前、课后各算几分钟可以自己调整。

### 管理课程

- **按来源分组**：课程分为课表中的课程、课表外的课程和文件名中发现的课程，可以按「课表中 / 课表外 / 待添加 / 时间不符 / 已忽略」筛选，按最近使用、照片数量或名称排序。
- **核对时间不符的照片**：照片拍摄于某节课的上课时间、文件名中却是另一门课程时，课签会提示核对。可以按课表一键修正，也可以确认保留文件名中的课程。
- **发现文件名中的课程**：照片文件名里已有的课程名称会被自动识别，可以直接加入课程列表。括号里只是备注时可以忽略，这些照片视为未标记，再次标记时保留原有后缀；忽略的名称可以在「已忽略」中恢复。
- **统一修改课程名**：修改课程名称时，相关照片同步重命名；新名称与已有课程相同时自动合并，两门课的上课时间都会继续用于识别。

### 重命名与撤销

- **重命名预览**：执行前逐张列出原文件名与新文件名，高亮新增、更换或移除的课程；同名冲突、文件名过长等问题会提前标出并自动跳过，也可以手动取消个别照片。
- **批量授权**：每批最多 2,000 张照片，全部批次授权成功后才开始改名，中途取消授权则所有照片保持原样。在设置中开启「免确认修改照片」后，不再逐次弹出系统确认。
- **随时撤销**：重命名完成后可以立即撤销，也可以在「重命名记录」中恢复最近 50 次批量操作。部分照片未能恢复时，记录会保留进度，处理冲突后可继续撤销。

### 命名格式与外观

- **命名格式**：内置全角括号（）、半角括号 ()、方括号 []、方头括号【】、下划线、短横线、话题标签七种格式，也可以自定义课程名前后的符号。更换格式后，旧格式的照片仍能识别，并可一键转换为新格式。
- **外观**：采用 Material 3 Expressive 设计与系统莫奈取色，可以跟随系统，也可以固定为浅色或深色模式；支持预测性返回手势，Android 13 起支持主题图标。

## 快速上手

1. 首次打开时允许课签访问照片。
2. （可选）在「课程」页导入课程表。以 WakeUp 课程表为例：在 WakeUp 中把课表导出为 ICS 日历文件，再在课签中选择该文件，确认课表名称和需要导入的课程。
3. 在「照片」页：
   - 点按「识别到 N 张课上照片未标记」，检查每节课的识别结果后预览并重命名；
   - 或者长按照片进入多选，点按悬浮工具栏中的标签按钮选择课程。
4. 在预览页确认新文件名，点按「重命名」，并在系统弹窗中允许修改。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `READ_MEDIA_IMAGES` / `READ_EXTERNAL_STORAGE` | 读取相册中的照片。Android 14 起支持只授权部分照片。 |
| `MANAGE_MEDIA`（可选） | 配合完整的照片读取权限和下述权限，免去系统的重命名确认。 |
| `ACCESS_MEDIA_LOCATION`（可选） | 仅在主动开启「免确认修改照片」时申请，用于满足系统免确认写入的权限要求；课签不读取照片位置。 |

课签不申请网络权限，照片、课程与课表只在本机处理。重命名只修改文件名，照片内容与拍摄信息保持不变。课程、课表和设置会随系统备份迁移到新设备；重命名记录和核对时确认保留的结果只保存在本机。

## 课程表解析

课签解析 WakeUp 课程表及常见日历应用导出的 ICS 文件，重复规则使用 [lib-recur](https://github.com/dmfs/lib-recur) 按 RFC 5545 展开：

- 折行、`TZID` 时区、UTC 与浮动时间；
- `RRULE` 重复规则，包括工作日、每月第几个星期几、月末工作日等，支持 `INTERVAL`、`UNTIL`、`COUNT`、`BYDAY`、`BYMONTHDAY`、`BYSETPOS` 等组合；
- `EXDATE`、`RDATE`、`RECURRENCE-ID` 单次调课与 `STATUS:CANCELLED`；
- WakeUp 课程表备注中的教室与任课老师；
- 全天事件与提醒（`VALARM`）不会被当作上课时间。

教学周以课表中最早一节课所在周的周一作为第 1 周。

未指定结束日期和次数的重复规则展开至首次上课后的两年；单个事件最多展开 1,000 次，超过时会提示缩短导出范围。暂不支持 `RANGE=THISANDFUTURE` 整段调课、同一事件的多条 `RRULE` / `EXRULE`，以及无法对应标准时区的自定义夏令时定义。遇到无法解析的规则时会中止导入并提示，不会静默跳过后继续匹配照片。

## 构建

- 运行环境：Android 11（API 30）及以上，目标 API 36
- JDK 17 或更高版本
- 构建工具：Gradle 9.8、Android Gradle Plugin 9.4、Kotlin 2.4

```bash
./gradlew assembleDebug        # 构建调试版 APK
./gradlew testDebugUnitTest    # 运行单元测试
```

调试版的包名带 `.debug` 后缀，可以和正式版同时安装。

## 技术栈

- Jetpack Compose、Material 3 Expressive（`material3 1.5.0-alpha`）
- Navigation 3（页面导航与预测性返回动画）
- MediaStore `createWriteRequest`（批量获取修改授权）
- Kotlin 协程、kotlinx.serialization（本地 JSON 存储）
- Coil 3（缩略图与大图加载）
- Haze（预览页的模糊栏）
- lib-recur（RFC 5545 重复规则解析与展开）

## 项目结构

```
app/src/main/java/com/happycola233/coursetag/
├── data/
│   ├── ics/          # ICS 日历解析与重复规则展开
│   ├── media/        # MediaStore 读取、缩略图加载与批量重命名
│   ├── naming/       # 命名格式、文件名解析与合法化
│   ├── schedule/     # 上课时段索引、照片与课程匹配、教学周
│   └── AppStore.kt   # 本地数据持久化
├── domain/           # 图库派生视图、重命名方案、课程与课表编辑
└── ui/               # Compose 界面：照片、课程、核对、设置、预览、识别确认等页面
```
